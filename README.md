# Airline Pricing Analysis

## Overview

Analysis of airline ticket pricing data using R to identify trends and patterns.

## Data

* `Indian_Airlines.csv`

## Tools

* R

## What It Does

* Performs exploratory analysis

## How to Run

1. Open `Airlines.R`
2. Ensure the CSV is in the working directory
3. Run the script
